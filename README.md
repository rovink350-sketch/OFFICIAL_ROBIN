# OFFICIAL_ROBIN1M — starter website

## Run
Open `index.html` in Chrome. No server is required for this demo.

## Admin
Click **Admin** and use the default password `0000`.
**Change `ADMIN_PASSWORD` in `script.js` before publishing.**

## Important
This starter stores data in browser `localStorage`, so it is NOT a real multi-device backend.
For production use, replace it with a server/database and a verified payment gateway/API.

The UPI ID configured in the UI is:
`8006485383-2@ybl`

Payment references are only collected here. The demo does NOT automatically verify UPI payments.
